## Documented Disease-Associated Variant

* **Variant:** NM_000500.9(CYP21A2):c.518T>A (p.Ile173Asn)
* **Common Name:** I173N
* **Mutation Type:** Missense single-nucleotide variant (SNV)
* **Nucleotide Change:** T → A at position c.518
* **Protein Change:** Ile → Asn at amino-acid position 173
* **ClinVar Accession:** RCV000012933

The I173N variant changes a single amino acid while preserving the overall reading frame and protein length. The computational analysis confirmed that the mutant protein remains 495 amino acids long without introducing premature stop codons.

## Artificial Mutation

An artificial single-nucleotide deletion was introduced at position c.518 (`del518`).

* **Deleted Nucleotide:** T
* **WT CDS Length:** 1,488 bp
* **Artificial Mutant CDS Length:** 1,487 bp
* **Mutation Type:** 1-nucleotide deletion / frameshift
* **Effect:** Disrupted downstream reading frame and introduced premature stop codons.
